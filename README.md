# Job Portal System 

A modern, responsive, and fully functional Job Portal web application built with HTML, CSS, JavaScript, and LocalStorage for state management. This project bridges job seekers and employers with a seamless user experience.

## 🚀 Features

### 👤 For Job Seekers:
* **Generic CV Profile Builder**: Save personal information, education, skills, and portfolio links once for one-click job applications.
* **Category-Wise Job Search**: Filter and search through available job listings based on specific industries (e.g., IT & Software, Data Science, UI/UX).
* **One-Click Apply**: Instantly apply to job openings using saved profile data.

### 🏢 For Employers:
* **Job Posting with Company Name**: Post job vacancies specifying the company name, category, salary range, and description.
* **Candidate Application Review**: Review incoming applications, view candidate credentials, skills, and access their portfolio links directly.

## 🛠️ Tech Stack
* **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS)
* **UI/UX Styling**: Modern responsive grid layouts, custom card shadows, and Inter typography.
* **State Management**: Browser `LocalStorage` for cross-page data synchronization.

## 📂 Project Structure
* `index.html` - Landing page with category grid and recent job listings.
* `login.html` - Unified login and registration system with role selection (Seeker/Employer).
* `seeker-dashboard.html` - Candidate dashboard for CV building, job filtering, and applying.
* `employer-dashboard.html` - Employer dashboard for posting jobs and reviewing applicants.

## 🖥️ How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Register accounts as an Employer to post jobs and as a Seeker to apply!
